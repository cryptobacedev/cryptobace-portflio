# Graphic design

**Put here:** Logos, brand kits, flyers, social media posts, crypto project visuals.

**Name files like this:** logo-brandname.jpg, flyer-eventname.jpg, social-pack-clientname-1.jpg

**Tip:** Export as JPG or WebP. Keep each picture under 500 KB so the site stays fast.

After you add a picture, open `index.html`, find the `WORKS` list, and add one line for it. The steps are in the main README.
