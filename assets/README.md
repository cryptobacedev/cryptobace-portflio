# Your own pictures

**Put here:** Your profile photo, your logo, and the sharing picture for WhatsApp and Facebook.

**Name files like this:** profile.jpg, logo.png, share-card.jpg

**Tip:** The share picture should be 1200 x 630 pixels.

After you add a picture, open `index.html`, find the `WORKS` list, and add one line for it. The steps are in the main README.
